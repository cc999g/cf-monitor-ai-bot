# CF Monitor AI Bot

Telegram-бот на **Cloudflare Workers**: **мониторинг использования аккаунта Cloudflare + ИИ-чат с несколькими моделями**.

> Это **оригинальный проект** (не создан на основе открытого проекта). Все функции и код написаны с нуля.

---

## ✨ Возможности

### 🧠 ИИ-чат
- **Режим чата по умолчанию**: просто введите текст для общения; команды начинаются с `/`
- **Трёхуровневая система моделей**:
  - ☁️ **Бесплатные модели Cloudflare** (5 постоянно встроенных: Qwen3-30B / GPT-OSS-120B / Llama 3.3 70B / Mistral Small 24B / Llama 3.1 8B)
  - 🔑 **Встроенный API** (постоянный, неудаляемый, напр. собственный релей)
  - 📦 **Временные API** (добавление через `/setapi`, удаление через `/delapi`, не влияет на первые два)
- **Свободный выбор модели**: панель с плюсами/минусами + метки источника (☁️/🔑/📦), предпочтения для каждого пользователя
- **Многоходовая память**: 5 пресетов (Лёгкая 1 ход → Максимум 40 ходов) + своя (`/mem ходы символов-на-сообщение`, до 100 ходов)
- **Новая сессия**: очистка памяти одним нажатием
- **Умный резерв**: автоматическое переключение на запасные модели при сбоях; при отказе всех временных API — переход на CF с уведомлением

### 📊 Мониторинг использования (официальные метрики CF)
- Запросы Workers: использовано / осталось сегодня (100 000/день, **сброс 00:00 UTC**)
- Использование ИИ: Neurons использовано / осталось (10 000/день, накапливается в KV при каждом вызове)

### 🔐 Многопользовательский доступ
- **Двухуровневые коды приглашения**: код администратора / код участника (изменяются в боте в любое время через `/setcode`)
- Суперадминистратор (`TG_CHAT_ID`) без проверки, всегда максимальные права
- Операции только для администратора: добавление/удаление API, изменение ключей, изменение кодов
- Предпочтения / память / выбор модели участников **изолированы для каждого пользователя**

### ⚙️ Управление пользовательскими API
- `/setapi url|ключ|модель1,модель2|имя` для добавления (не перезаписывает существующее, автоматически становится основной моделью)
- `/setkey имя новый-ключ` для смены ключа (KV — единственный источник истины, действует мгновенно)
- Проверка формата URL (должен быть http/https)

### 🎛️ UX
- Постоянная быстрая клавиатура, не нужно искать команды
- Панельный режим: смена модели обновляет панель на месте + подтверждение toast
- Проверка подписи Webhook (`secret_token`), блокировка поддельных запросов

---

## 🏗️ Архитектура

```
Пользователь Telegram → Webhook (проверка подписи) → Cloudflare Worker
                      ├─ Workers AI (бесплатные модели)
                      ├─ Пользовательский API (совместимый с OpenAI)
                      ├─ CF GraphQL (запрос использования)
                      └─ KV (конфиг / память / использование / доступ, сохраняется)
```

## 🚀 Развёртывание

### ⚡ Вариант 1: Развёртывание в один клик (рекомендуется)

Только 4 обязательных поля, всё остальное генерируется автоматически:

**1. Подготовка**
- Аккаунт Cloudflare
- Токен Telegram-бота (создать через @BotFather)
- Node.js 18+ на машине развёртывания

**2. Заполнение конфигурации**

```bash
cp .env.example .env
```

Отредактируйте `.env` — 4 обязательных поля:

```ini
CF_API_TOKEN=ваш токен API Cloudflare
CF_ACCOUNT_ID=ваш ID аккаунта Cloudflare
TG_BOT_TOKEN=ваш токен Telegram-бота
TG_CHAT_ID=ваш ID чата Telegram
```

> Остальные поля (коды приглашения, SETUP_KEY, секрет webhook) можно оставить пустыми — скрипт сгенерирует случайные значения и выведет их.

**3. Запуск скрипта развёртывания**

Windows (PowerShell):
```powershell
powershell -ExecutionPolicy Bypass -File .\deploy.ps1
```

Linux / macOS:
```bash
chmod +x deploy.sh && ./deploy.sh
```

Скрипт автоматически: создаёт/использует namespace KV → генерирует недостающие секреты → настраивает wrangler → устанавливает все Secrets → развёртывает Worker.

**4. Регистрация webhook**

После развёртывания скрипт выведет команду curl (с сгенерированным SETUP_KEY). Скопируйте и выполните:

```bash
curl "https://cf-monitor-ai-bot.<ваш-поддомен>.workers.dev/setup" -H "X-Setup-Key: <SETUP_KEY>"
```

**5. Начало работы**
Отправьте боту в Telegram код администратора (или код участника) для активации.

### 🔧 Вариант 2: Ручное развёртывание

### 1. Подготовка
- Аккаунт Cloudflare
- Токен Telegram-бота (создать через @BotFather)
- Окружение Node.js 18+

### 2. Создание namespace KV
Cloudflare Dashboard → Workers & Pages → KV → создайте namespace, впишите его ID в `wrangler.toml`.

### 3. Настройка `wrangler.toml`
Замените `<заглушки>` своими значениями: ID namespace KV, ID аккаунта CF, ID чата TG.

### 4. Настройка Secrets

```bash
cd cf-bot-public
npx wrangler@4 secret put TG_BOT_TOKEN        # Токен Telegram-бота
npx wrangler@4 secret put CF_API_TOKEN        # Токен API Cloudflare (нужно разрешение GraphQL; используйте Edit All Resources)
npx wrangler@4 secret put SETUP_KEY           # Ключ админ-маршрута /setup (длинная случайная строка)
npx wrangler@4 secret put TG_ACCESS_CODE      # Код приглашения администратора
npx wrangler@4 secret put TG_MEMBER_CODE      # Код приглашения участника
npx wrangler@4 secret put TG_WEBHOOK_SECRET   # Секрет подписи webhook (случайный)
```

### 5. Развёртывание

```bash
CLOUDFLARE_API_TOKEN=<ваш-токен-API-CF> \
CLOUDFLARE_ACCOUNT_ID=<ваш-ID-аккаунта> \
npx wrangler@4 deploy
```

### 6. Регистрация webhook

```bash
curl "https://<ваш-домен-Worker>/setup" -H "X-Setup-Key: <SETUP_KEY>"
```

> Админ-маршруты `/setup` и `/debug` используют **проверку заголовка запроса** (`X-Setup-Key`) — ключ не появляется в URL.

### 7. Использование
- Суперадминистратор работает сразу (`TG_CHAT_ID`)
- Остальные активируются кодом администратора или участника

## 📜 Команды

| Команда | Описание | Доступ |
|---|---|---|
| `/status` | Проверить использование | Все |
| `/ai вопрос` | ИИ-чат (или просто введите текст) | Все |
| `/mem ходы символов` | Настроить глубину памяти | Все |
| `/new` | Очистить память, новая сессия | Все |
| `/setapi` | Добавить пользовательский API | Админ |
| `/delapi` | Удалить временный API | Админ |
| `/setkey` | Изменить ключ API | Админ |
| `/setcode` | Установить двухуровневые коды приглашения | Админ |

---

## 🔒 Примечания по безопасности
- Все секреты хранятся в Cloudflare Secrets, никогда в коде
- KV — единственный источник истины для конфигурации (`cfg:apis`), изменения действуют мгновенно
- Webhook проверяет `secret_token`; админ-маршруты проверяют заголовки запросов
